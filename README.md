A make.fun bounty entry for [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e): one line, at most 200 characters, in which a home Wi-Fi router excuses itself for dropping the connection at the climax of a movie.

## The entry

> I cut you off at the climax — the killer was about to confess, and I wanted to hear it before you did.

The router is not sorry and it is not broken. It cut the household off on purpose, because it carries every packet — and it wanted the twist first.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`. It is deterministic: the same bytes on every run.
